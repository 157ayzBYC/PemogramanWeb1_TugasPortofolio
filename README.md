## 📖 Deskripsi Proyek
Website ini dirancang dengan konsep *Single-Page Website* menggunakan navigasi *smooth scrolling* antar bagian:
- **Hero / Home** : Perkenalan singkat dan identitas developer.
- **About** : Profil diri, foto profil, dan ringkasan keahlian.
- **Portfolio / Projects** : Showcase proyek dan karya.
- **Contact** : Form interaksi serta tautan media sosial dan GitHub.

---

## 🛠️ Teknologi yang Digunakan
Sesuai dengan ketentuan tugas, website ini dibangun murni tanpa framework eksternal:
- **HTML5** : Struktur dokumen semantik (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3** : Tata letak murni menggunakan Flexbox & CSS Grid, CSS Variables, dan efek visual custom.
- **Responsive Web Design** : Tampilan adaptif untuk desktop, tablet, dan smartphone menggunakan media queries.
